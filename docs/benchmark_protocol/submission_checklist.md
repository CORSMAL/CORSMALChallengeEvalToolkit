# 📋 **Submission Checklist**

Teams must complete **all** items below before submitting.

---

## ✅ **A. Experiment Preparation**
- [ ] Recruited **4 volunteers** to perform the 288 configurations  
- [ ] Obtained **informed consent** from all volunteers  
- [ ] Ensured compliance with **local ethics requirements**  
- [ ] Prepared the **two‑camera vision setup** (or equivalent)  
- [ ] Verified that only **hands and objects** appear in recordings  

---

## ✅ **B. Safe Recording**
- [ ] Cameras positioned to avoid faces and identifiable features  
- [ ] Background cleared of posters, screens, documents, personal items  
- [ ] Audio disabled or contains no speech  
- [ ] Volunteers removed jewellery, watches, badges, distinctive clothing  
- [ ] All videos reviewed for anonymisation  
- [ ] Videos uploaded as **private links** (not public)

---

## ✅ **C. Execution of the 288 Configurations**
- [ ] All configurations executed according to the CORSMAL protocol  
- [ ] All required measurements recorded  
- [ ] No missing or corrupted data  

---

## ✅ **D. Submission CSV**
Headers must match **exactly**:

```
configuration_id,
width_top_mm,
width_bottom_mm,
height_mm,
mass_full_vision_g,
fill_level_percent,
mass_full_robot_g,
placement_error_mm,
mass_final_g,
time_human_maneuvering_ms,
time_handover_ms,
time_robot_maneuvering_ms
```

- [ ] CSV uses **comma separators**  
- [ ] No additional columns  
- [ ] No renamed headers  
- [ ] Missing values represented as `null`  
- [ ] Numeric fields use **dot** as decimal separator  

---

## ✅ **E. Metadata JSON**
- [ ] Includes team information  
- [ ] Includes configuration file hash  
- [ ] Includes physical assumptions  
- [ ] Includes ethics compliance block  
- [ ] Includes optional demographics (coarse categories only)  
- [ ] Includes video links  

---

## ✅ **F. Video Evidence**
- [ ] One video per configuration (or grouped as allowed)  
- [ ] All videos anonymised  
- [ ] All links accessible to organisers  
- [ ] No identifying content present  

---

## ✅ **G. Final Packaging**
- [ ] Submission CSV  
- [ ] Metadata JSON  
- [ ] Video links  
- [ ] Optional logs  

Packaged according to the submission instructions.
